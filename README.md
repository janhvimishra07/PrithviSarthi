# 🌍 PrithviSaarthi – Climate Awareness Platform  
🏆 NASA Space Apps Challenge Winner  

---

## 📌 Project Overview

PrithviSaarthi is an interactive climate awareness platform developed during the NASA Space Apps Challenge. The platform aims to promote environmental education by combining data analytics, visualization, and structured climate learning resources.

It transforms raw global climate datasets into meaningful, interactive insights to help users understand long-term environmental trends.

---

## 🎯 Objective

- Promote climate awareness through data-driven storytelling  
- Visualize global environmental changes from 1965–2021  
- Provide interactive dashboards for better understanding of emissions and sustainability trends  
- Encourage informed decision-making through climate analytics

---

## 📊 Climate Analytics Dashboard Features

- 🌍 Greenhouse gas emissions analysis  
- 🌡️ Global land-ocean temperature trend visualization  
- 🌊 Sea level rise tracking  
- 🔋 Renewable energy adoption comparison (Hydro, Solar, Wind, Biomass)  
- 🏭 Sector-wise greenhouse gas contribution  
- 📅 Year range filter (1965–2021)  
- 🌎 Country-level interactive filtering  

---

## 🛠️ Tech Stack

- Power BI  
- DAX (Data Analysis Expressions)  
- HTML  
- CSS  
- Climate datasets (CSV format)
